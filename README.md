# 🚀 NASA-APOD Webapp — React JS NASA Astronomy Picture App

A React based web application that uses the **NASA APOD (Astronomy Picture of the Day) API** to show daily space imagery and related information. Users can explore stunning astronomy pictures updated each day, along with title and description data fetched from the NASA API. :contentReference[oaicite:1]{index=1}

🌐 **Live Demo:** https://apod-nasa-webapp-reactjs.netlify.app/

---

## 🧠 About the Project

This project demonstrates:

* Fetching data from NASA’s public APIs
* Displaying the Astronomy Picture of the Day (APOD)
* Clean and responsive UI using React components
* Modern frontend tooling with **Vite**

The project purpose is to explore external API integration and learn how to manipulate and render dynamic content in a React web app.

---

## 🚀 Features

✔️ Display NASA’s Astronomy Picture of the Day  
✔️ Show title and description for the APOD  
✔️ Clean and minimal responsive UI

## ⚙️ Getting Started

### Prerequisites

Make sure you have Node.js installed:

```bash
node -v
npm -v
```

---

### Installation

```bash
git clone https://github.com/Hari-Prasanth-J-26/reactjs-NASA-webapp.git
cd reactjs-NASA-webapp
npm install
```

---

### Run Locally

```bash
npm run dev
```

Then open in browser:

```
http://localhost:5173
```
